# End-to-End Credit Card Fraud Detection Pipeline

An end-to-end Machine Learning pipeline for credit card fraud detection built with Scikit-Learn, Random Forest, and FastAPI.

## Project Structure
- `data/`: Contains dataset instructions.
- `notebook/`: Exploratory Data Analysis (EDA) and model experimentation.
- `main.py`: FastAPI web application wrapper.
- `predict.py`: Inference engine script.
- `random_forest_fraud_model.joblib`: Serialized trained model and scalers.
